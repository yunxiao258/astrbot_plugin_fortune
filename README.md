# AstrBot 运势占卜插件

**作者**：云晓
**版本**：1.1.1
**许可证**：MIT（详见 LICENSE）

AstrBot 运势占卜插件：每日运势（连续占卜加成）、欧皇榜、星座运势、生肖运势、抽签占卜、缘分配对。

## 功能

### 今日运势（`/运势`）
- 随机生成当日运势：总评（星级 + 分数 + 等级）、幸运色、幸运数字、宜、忌、一句话
- 内容库共 80+ 条组件（幸运色 12 种、宜 12 种、忌 12 种、评语 25 条、一句话 15 条、忠告 12 条），组合结果丰富
- **每人每日一次**：当日已占卜过的用户重复查询会返回当天已生成的运势，命运不变（v1.1.0 起按"会话 + 用户"隔离，同群不同人各自占卜）
- **连续占卜加成**（v1.1.0）：连续第 N 天额外 +2 分/天，封顶 +10；加成后自动重新定档，可通过 `streak_bonus_enabled` 关闭
- 记录持久化到 `plugin_data`，重启后依然有效

### 欧皇榜（`/运势榜`，v1.1.0）
- 展示当前群今日所有已占卜用户的分数排行 Top10（🥇🥈🥉）
- 显示今日欧皇（最高分者）；仅统计本群记录，跨群隔离

### 缘分配对（`/缘分 <@对方 或 名字>`，v1.1.0）
- 双人缘分值 5~99 + 等级评语（天作之合 / 情投意合 / 暗生情愫 / 缘分尚浅 / 相看两厌）
- 按「双方标识 + 日期」哈希生成：**同日同对结果一致，且与发起顺序无关**
- 支持 @ 对方（消息组件）或直接输入名字

### 星座运势（`/星座 <星座名>`）
- 12 星座内置文本模板（日期区间、元素、性格描述）
- 固定随机种子按「日期 + 星座」生成，**同日同星座结果一致**
- 支持别名：双鱼 / 双鱼座 / 水瓶 / 天平 / 摩羯座 等

### 生肖运势（`/生肖 <生肖>`）
- 12 生肖内置文本模板，同星座运势机制，同日同生肖结果一致
- 支持 属牛 / 生肖牛 等写法

### 抽签占卜（`/抽签 <问题>`）
- 内置签文库 30 签（上上 6 + 上 8 + 中 10 + 下 6），每签附签诗与解签文
- 按「问题 + 日期」哈希取签，**同一问题同日结果一致**

### 帮助（`/占卜`）
- 显示全部指令的用法列表

## 指令表

| 指令 | 说明 |
|------|------|
| `/运势` | 今日运势（每人每日一次，连续占卜有加成） |
| `/运势榜` | 群内今日欧皇榜 Top10 |
| `/星座 <星座名>` | 星座今日运势（支持别名） |
| `/生肖 <生肖>` | 生肖今日运势 |
| `/抽签 <问题>` | 抽签占卜（同题同日结果一致） |
| `/缘分 <@对方 或 名字>` | 缘分配对（同日同对结果一致） |
| `/占卜` | 显示帮助列表 |

指令参数解析兼容带 `/`、`／` 或不带斜杠的前缀（如 `运势`、`/星座 双鱼`、`／生肖 牛`）。

## 配置表

见 `_conf_schema.json`：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable_persistence` | bool | `true` | 是否启用磁盘持久化（关闭后仅内存记录） |
| `max_daily_records` | int | `1000` | 每日运势记录最大条数，超出自动清理最旧记录 |
| `keep_days` | int | `7` | 每日运势记录保留天数，过期自动清理 |
| `lucky_number_max` | int | `99` | 幸运数字范围上限（1~N） |
| `streak_bonus_enabled` | bool | `true` | 是否启用连续占卜加成（+2 分/天，封顶 +10） |

配置脏值（非数字 / 不可识别布尔）会自动回退默认值，不会导致插件崩溃。

## 数据

存储于 `plugin_data/astrbot_plugin_fortune/`：

- `fortune_data.json`：今日运势记录（按日期 + 会话 + 用户保存，含连续天数与昵称）
